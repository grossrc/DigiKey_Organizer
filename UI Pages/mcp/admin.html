MCP Information and Setup show/collapse

This inventory system's "MCP" allows LLMs to interface with the database and answer broad questions. Different database tools are provided to personal LLMs like ChatGPT, Claude, VScopilot, etc. which they use to interface and gather relevant data about your local stock to answer questions. The tools are read-only, so an LLM cannot change anything in your database.

This is valuable when designing circuits with the help of LLMs whose access to internal inventory can save time, money, and effort by sourcing from local stock rather than buying new components.

Example of MCP use

With the data the LLM has access to in the database (component P/N, quantity, price, datasheet, package, etc.), it's capable of answering almost anything. This is an example ChatGPT thread I had regarding my local inventory.

Setting Up This Program for MCP Connection

There is one quark of setting up an MCP (put your wallet away!) which is that you have to set up a free ngrok account. This inventory system enjoys the safety of your local network which is not the case on the open internet. LLM's require access to the MCP via the open internet, so the workaround is to allow tunnel access via ngrok to this server from encrypted keys generated safely on this page (note that people on your network might also have access). In other words, you generate a unique Key here on your local network used to grant MCP access from an LLM trying to get in from the outside. If at any point a key is compromised:

  • No attacker can modify or change anything in the database
  • Access can be revoked on this page at any time
  • New keys can be generated and managed

Steps:

  1. Create a free ngrok account.
    • If prompted, select Share Localhost
  2. In your ngrok account:
    • Copy the Authtoken from your dashboard and paste it into the bottom of this page
    • Copy the Domain URL from your dashboard and paste it into the bottom of this page
  3. Generate a key in the Access Keys section below, and copy the connection URL.
  4. On your preferred LLM dashboard there will be an option for MCP connection, New Plugin (ChatGPT), or something similar.
    • Paste the connection URL or mcp.json into your LLM's plugin settings.
    • Select "No Auth" if prompted (authorization is embedded in your link).
  5. Test the plugin by asking a basic question about your database.

Access keys

Give each client its own key so you can disable just that one later. In ChatGPT, paste the URL and set authentication to No authentication — the key is in the URL. Clients that support headers can instead send Authorization: Bearer <key>.
